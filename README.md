# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 每次改动登记为待复核批次：改动步骤与全部下游步骤一并退回待复核，复核员逐项确认后批次才结案；同一步骤再次改动时，其它未结批次里的旧确认自动作废。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止逐项确认与冻结。
- 提交复核后，复核人可逐条添加批注、标记解决、在批次内逐项确认或退回；待办批次与历史批注均保存在本机，重开页面不丢失。
- 冻结版本前校验未处理批次；存在未结批次时点击冻结会列出具体原因。所有批次结案、步骤确认且安全信息完整后才能冻结，冻结后只能从该版本创建修订稿。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化，并标注每个改动步骤影响到的下游步骤。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
